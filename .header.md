# Terraform STACKIT MariaDB Flex module

Terraform module which provisions a [STACKIT MariaDB](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/mariadb_instance) Flex instance and its credentials on [STACKIT](https://www.stackit.de/en/).

This repository is not from the official STACKIT organization.

> **Naming.** The repository is `terraform-stackit-flex-mariadb` (readability), while the provider
> resources are `stackit_mariadb_instance` / `stackit_mariadb_credential`.

## Usage

```hcl
module "flex_mariadb" {
  source  = "terraform-stackit-modules/flex-mariadb/stackit"
  version = ">= 1.0.0"

  project_id      = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name            = "app-mariadb"
  mariadb_version = "10.11"
  plan_name       = "stackit-mariadb-1.2.10-replica"

  parameters = {
    sgw_acl = "0.0.0.0/0"
  }

  credentials = {
    app = {}
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Examples

- [`basic`](./examples/basic) — minimal instance + one credential.
- [`complete`](./examples/complete) — prod-like: monitoring/metrics parameters, restricted ACL,
  and multiple credentials (app + read-only). Mirrors `complete-mysql` in terraform-aws-rds.
- [`replica`](./examples/replica) — high availability. NOTE: STACKIT MariaDB replication is carried
  by the **plan** (a `-replica` plan provisions a managed primary/replica topology); there is no
  RDS-style `replicate_source_db` resource to wire to a source.

## Composite module

This is a composite module with independently usable sub-modules:

- `modules/instance` — the `stackit_mariadb_instance` (toggled by `create_instance`).
- `modules/credential` — `stackit_mariadb_credential` entries (`for_each` over `credentials`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for credential management.

## Notes

- Generated credentials (`password`, `uri`) are exposed via **sensitive** outputs.
- `credentials` is a map keyed by a **stable identifier**; the instance_id (known after apply when
  the instance is created here) is only a resource attribute, never a `for_each` key.
- MariaDB has no separate database/user resources in the provider — access is via credentials.

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-flex-mariadb
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
